# Android SDK 37 build configuration

- Problem: release APK assembly failed because `flutter_secure_storage` requires compile SDK 37, while the app used SDK 36 and Android Gradle Plugin 9.1.0.
- Fix: set `compileSdk = 37` and upgraded the Android application plugin to 9.4.1, which is already available in the local Gradle cache.
- Updated the Gradle wrapper from 9.3.1 to 9.6.0, the minimum supported version required by AGP 9.4.1.
- `targetSdk` and `minSdk` remain managed by Flutter and were not changed.
