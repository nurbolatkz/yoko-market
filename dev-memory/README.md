# Development Memory

This folder contains short records of meaningful project changes. Add one
Markdown file after each completed change so future work can quickly recover
the context behind the implementation.

## File naming

Use `YYYY-MM-DD-short-topic.md`, for example:

```text
2026-10-07-storefront-redesign.md
```

If several changes share a date and topic, add a short distinguishing suffix.

## Required sections

Each entry should remain concise and include:

- Problem
- Fix
- Project structure affected
- Changes
- Verification

Copy `_template.md` when creating a new entry.
